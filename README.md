# 私信助理（WeReplyAI）

> **程序员的恋爱嘴替。** 嘴笨没关系，AI 帮你把天聊下去。

---

## 缘起

程序狗总是嘴比较笨——写得了循环，接不住暧昧；debug 一晚不带困的，
女神一句「在吗」能盯着输入框憋半小时，最后回个「在」。

于是有了这个工具：一个悬浮球。你把对话复制给它，它拆成一轮一轮交给 AI，
生成几条不同风格的回复，点一条就复制好，回微信粘贴、发送。

它不替你做决定，只在你张嘴之前递上一份小抄。
祝愿每一个嘴笨的程序狗，都能靠这份小抄把心里的话说明白——
**祝有情人终成眷属。** 🐶❤️

---

## 功能一览

- 🫧 **悬浮球一键出回复**：复制对方消息 → 点球 → 挑一条 → 自动复制好
- 🗂 **长按攒对话**：长按球显示剪贴板对话，逐条切换「对方 / 我」，攒够了再生成
- 🧠 **45 个场景段子库**：对方说「吃饭了吗」「我去洗澡了」，自动带上对应场景的经典段子
- 🎚 **油腻度滑块**：0~100 五档调节土味情话和舔狗腔的浓度，清爽到齁咸随意切换
- 🎭 **6 种表达风格**：高情商 / 理性 / 尖酸 / 高冷 / 俏皮 / 自定义，多选横向对照
- 🔒 **零侵入**：默认剪贴板模式不读屏幕、不读通知、不用无障碍，微信侧无任何异常
- 📦 **数据全本地**：配置和对话只存在本机，消息只发给你自己填的 AI 接口

默认人设是一个「女神的头号舔狗」——在 App 的人设卡片里随便改，
prompt 和段子库都会跟着人设走。

## 快速开始

### 准备（2 个权限）

1. 装好 APK（见下方「构建」）
2. 打开 App，把「准备工作」两项打勾：**允许发送通知** + **允许显示悬浮窗**
3. 点「启动悬浮球」
4. 顺手填两处：**你自己的微信昵称**（分角色用）、**AI 接口的 API Key**

### 轻点球 —— 一条消息，直接出候选

1. 微信里长按对方那条消息，选「复制」
2. 轻点球，等一两秒
3. 挑一条，点它就复制好了
4. 回微信输入框长按，粘贴，发送

### 长按球 —— 显示剪贴板对话

长按球把剪贴板里的内容直接读出来，列成一条条对话，确认谁是谁再生成：

| 按钮 | 干嘛的 |
| --- | --- |
| 读剪贴板 | 反复点。复制一条，收一条，攒着 |
| 用粘贴的 | 长按上面的框粘贴整段对话，点这个收进来 |
| 角色对调 | 谁是谁判反了，一键翻过来 |
| 清空 | 换人聊天时点 |
| 生成回复 | 改对了点这个 |

列表里每条**点一下**切换「对方 / 我」，**长按**删掉。
复制一条长按一次球，就能一条条攒起来；复制的是整段对话就一次列全。
选中的候选会自动记成你说的那条，接着聊不用重新攒。

## 多条对话怎么进剪贴板

先泼盆冷水：**安卓微信的「多选」底部只有删除、转发、收藏，没有「复制」。**
实际能走的是这几条：

| 办法 | 步数 | 说明 |
| --- | --- | --- |
| 一条条复制 + 反复点「读剪贴板」 | 每条 3 下 | 安卓上最实际的路，攒几条点几次 |
| 多选 → 收藏 → 我·收藏 → 打开 → 转为笔记 → 全选复制 | 约 6 下 | 一次拿到整段，粘进面板的框里 |
| 微信电脑版多选复制 | 1 下 | 电脑版真的能多选复制，格式是「昵称 + 时间戳」，解析器认得 |

### 解析器认得四种形状

按可靠性从高到低依次尝试，第一个认出来的算数：

| 形状 | 长什么样 | 谁会产生 |
| --- | --- | --- |
| 时间戳抬头 | `小王 2026-09-08 10:23:45` 换行 `在吗` | 微信电脑版多选复制、邮件备份 |
| 行内前缀 | `小王：在吗` | 收藏转笔记、各种导出工具 |
| 昵称独占一行 | `小王` 换行 `在吗` | 部分笔记导出 |
| 都不认识 | —— | 整段当成对方连发的一段，不丢内容 |

解析结果会显示在面板顶上：用了哪种格式、拆出几条、对方是谁、你说了几条。
不对当场改。**猜错不会罢工**——宁可判错让你一键翻过来，也不弹一句「解析失败」把你晾在那儿。

- 填了自己的微信昵称 → 按昵称对，最准
- 没填 → 把整段最后说话的那个人当成对方（你本来就是在回他）
- 判反了点「角色对调」，或单条点一下切换

复制聊天记录带进来的噪声行（「以下为新消息」、单行时间、撤回提示、分隔线）自动丢掉；
超过 8000 字只留最后一段，发给接口前再按预算从后往前裁、合并连续同角色。

## 人设与油腻度

**人设卡片**里写你是谁、怎么说话，写得越具体回复越像你：

> 默认：我是女神的头号舔狗，随叫随到、有求必应，女神说的永远是对的。
> 说话嘴甜、卑微但可爱，爱自嘲，习惯用「嘿嘿」「遵命」「来了来了」，永远秒回。

**油腻度滑块**（0~100）控制土味情话和舔狗腔的浓度：

| 档位 | 数值 | 效果 |
| --- | --- | --- |
| 清爽 | 0~19 | 正常聊天，禁止土味情话、彩虹屁和舔狗腔 |
| 自然 | 20~39 | 正常为主，偶尔俏皮 |
| 微甜 | 40~59 | 可以嘴甜、偶尔用段子 |
| 油腻 | 60~79 | 土味情话和舔狗语录放开用 |
| 齁咸 | 80~100 | 每句都往舔狗味写，土到极致 |

两处联动：prompt 会写明当前档位要求；段子库里的重油素材（土味情话、舔狗自嘲）
只在 40 及以上才喂给 AI——省 token，也防止清爽模式串味。

## 表达风格

勾几种就出几条，**每种风格各一条**，横向对照着挑；
只勾一种就是同一风格出 5 条不同写法。

| 风格 | 写出来什么样 |
| --- | --- |
| 高情商 | 先接住对方的情绪再回应，舒服但不给承诺 |
| 理性 | 就事论事，不带情绪词，不寒暄不反问 |
| 尖酸 | 带刺、反讽、绵里藏针，点到为止 |
| 高冷 | 三到八个字，让话题降温 |
| 俏皮 | 轻松玩笑、接梗 |
| 自定义 | 自己写一段风格描述，比如「东北话，自来熟」 |

想加风格改 `Tone.kt` 加一个枚举项就行，选择器和 prompt 拼装都是遍历 `entries` 自动出来的。

### 内置段子库

「内置段子库」开关（默认开）会给 AI 喂两批素材：

**按场景匹配**——发请求前本地关键词匹配对方最近两条消息，最多带 3 个场景：

| 对方说 | 匹配场景 | 示例段子 |
| --- | --- | --- |
| 「吃饭了吗」 | 吃饭 | 吃了，但没你香 |
| 「我去洗澡了」 | 洗澡 | 去吧，我帮你看着时间，泡太久会皱 |
| 「晚安」 | 睡觉 | 睡吧，明早我的早安比闹钟先到 |
| 「在吗」 | 打招呼 | 只要是你问，我都在 |
| 「想你了」 | 想你 | 巧了，我也在想你 |
| 「对不起」 | 道歉 | 行，先原谅你一半，剩下的看你表现 |
| 「烦死了」 | 心情不好 | 先抱抱，天塌下来我陪你顶着 |
| 「可以借我点钱吗」 | 借钱 | 谈钱伤感情，谈感情伤钱，你选一个 |

共 45 个场景：吃饭、洗澡、睡觉、早安、失眠、噩梦、打招呼、在干嘛、冷场、回晚了、
想你、夸人、道谢、道歉、心情不好、开心事、敷衍、被怼、好人卡、失恋、前任、催婚、
借钱、红包礼物、请客、要照片、迟到、迷路、没电断网、暂离、上班、考试、游戏、喝酒、
点歌、直播、周末、旅游、健身、做饭、生病、天气、无聊、节日、生日。

**按风格匹配**——看你勾了哪种风格：高情商话术、反讽金句、土味情话、舔狗日记式自嘲、
极简降温句。

素材是工具箱不是稿子：不贴切就自己写，不会硬套；土味情话和舔狗自嘲只在轻松打趣时用，
对方认真、生气或说正事时一律不用。想加段子改 `ReplyBank.kt`：场景往 `SCENARIOS` 加一行
（配关键词），风格往 `POOLS` 对应桶加一行。

## 为什么不做读屏识别

这个项目早期做过读屏（无障碍服务读微信界面）和自动识别，后来整个删掉了：

- 微信的界面结构靠猜，**一改版就失灵**，识别效果约等于没有
- 无障碍行为特征明显，**封号风险高**
- 剪贴板模式完全不依赖任何微信内部信息，微信怎么改版都影响不到它

所以现在只剩两条路：**剪贴板（默认，零风险）+ 通知监听（可选）**。

## 高级模式（可选，默认折叠）

在「高级模式」卡片里展开，能切到通知模式（自动监听微信通知、免手动复制）：

| | 剪贴板 | 通知模式 |
|---|---|---|
| 要开的权限 | 2 个 | 4 个 + 微信设置 |
| 触发方式 | 手动复制 + 点球 | 自动 |
| 上下文 | 你复制多少算多少 | 只有通知那一条 |
| 支持哪些 App | 所有 | 微信为主 |
| 封号风险 | 无 | 低 |

通知模式靠通知栏的快捷回复通道，自动触发，代价是权限多、有风险。
白名单、节流、免打扰时段、全自动直接发这些设置只对通知模式有意义。
**剪贴板模式够用就别碰这里。**

## 内容红线

候选只做两件事：非空、不超过 200 字。内容上不设限，该冷就冷、该呛就呛，
最终由你自己从候选里挑。只有三条约束：

1. **不引导付费**：不主动引导对方打赏、转账、充值、投资（留在 prompt 里，不拦候选）
2. **尖酸不参与全自动**：机器不替你决定什么时候呛人，尖酸候选永远要自己点
3. **不骂街**：尖酸要的是反讽，不是人身攻击

## 构建

### GitHub Actions（推荐）

仓库自带 `.github/workflows/build.yml`：**push 即自动构建**，
到 Actions 页面下载 `wereply-debug-apk` 工件。

### 本地构建

```bash
# 需要 JDK 17 + Android SDK
gradle assembleDebug
# 产物在 app/build/outputs/apk/debug/
```

- Android 8.0（API 26）及以上
- 一个 OpenAI 兼容接口的 API Key（DeepSeek / 通义 / Kimi / 智谱均可）

| 服务 | 接口地址 | 模型名 |
| --- | --- | --- |

## 项目结构

```

├── ClipboardBallService.kt    悬浮球前台服务（剪贴板主流程）
```

## 数据与隐私

- 所有配置和对话上下文存在本机 SharedPreferences 里，**没有服务端**
- 消息内容只会发给你自己填的那个 AI 接口，除此之外不出本机
- 默认剪贴板模式不申请任何微信相关权限

## 已知限制

- 群聊不处理；合并通知抓不到
- 只能处理文字：图片、语音、视频、红包、转账在通知里是 `[图片]` 这类占位符
- 拿不到聊天历史：上下文靠你自己复制/粘贴进来，最多保留 40 条
- 通知被清掉就发不出去了（快捷回复通道挂在原通知上）
- 抖音私信不一定带 RemoteInput 回复通道，需自行实测
- 安卓微信没有一键多选复制（微信的限制，绕法见上文）
- 部分厂商会弹「私信助理读取了剪贴板」的提示——Android 10+ 只有持焦点的窗口能读剪贴板，正常现象
- 通知模式的高频、规律化行为可能触发平台风控，建议先拿小号跑几天
