# 私信助理（WeReplyAI）

用 Android 的通知监听 + 通知快捷回复通道，让 AI 帮你起草私信回复。
不注入微信进程、不用无障碍模拟点击、不需要 root。

## 出 APK

容器里没有 Android SDK，编不出包。把整个目录推到 GitHub，
Actions 会自动跑 `.github/workflows/build.yml`，跑完在 Actions 页面下载
`wereply-debug-apk`。

```bash
cd WeReplyAI
git init && git add . && git commit -m "init"
git remote add origin git@github.com:你的账号/WeReplyAI.git
git push -u origin main
```

## 装好之后

打开 App，最上面是「准备工作」清单，每一项都会**实时检测真实状态**，
✓ 的收起来，✗ 的展开显示为什么需要 + 具体点哪里，右边有按钮直接跳过去。
从系统设置页返回时会自动重新检测，不用手动刷新。

清单会跟着工作模式变 —— 通知模式要「通知使用权」，无障碍模式要「无障碍服务 + 悬浮窗」，
切换模式后清单自动换。

全部打勾之后，再填 API Key、写人设、勾风格、把要处理的人加进白名单，最后开总开关。

### 清单里最容易翻车的两项

**电池优化**和**自启动保活**。这个 App 的头号故障不是功能有 bug，
是「装好了用两小时就不灵了」，几乎都是国产 ROM 把后台服务冻结了。

清单里的自启动那项会按你手机的品牌给出不同文案（小米/华为/OPPO/vivo/魅族/三星各一套），
「去设置」按钮会挨个尝试该品牌的自启动管理页组件名，都打不开就退回应用详情页。
这类页面的组件名随 ROM 版本变，打不开是正常的，照着文字路径手动找就行。

小米用户额外注意：除了自启动，还要在「授权管理 → 其他权限」里打开
**后台弹出界面**，否则无障碍模式的悬浮球弹不出来。

另外记得在最近任务界面下拉本应用的卡片**加个锁**，防止一键清理干掉服务。

### 系统查不到的两项

「自启动保活」和「微信显示消息详情」这两项系统没法检测，靠你自己点「我按上面弄好了」标记。
标错了可以再点「重新标记为未完成」退回去。

## 两种模式

设置第 ① 张卡片切换，两者互斥（无障碍模式开着时通知服务自动让路，
同时开只会多一个被识别的面）。

| | 通知模式 | 无障碍模式 |
|---|---|---|
| 拿到的上下文 | 只有通知那一条 | 屏幕上可见的完整聊天记录 |
| 群聊 | 跳过 | 跳过 |
| 合并通知 | 抓不到 | 不受影响 |
| 抖音 | 不一定有回复通道 | 可用 |
| 图片语音红包 | 只有占位符 | 只有占位符 |
| 怎么发出去 | 通知自带的 RemoteInput 通道 | 填进输入框 |
| 被发现的风险 | 低（纯系统 API，不碰微信界面） | 明显更高 |
| 要开的权限 | 通知使用权 | 无障碍 + 悬浮窗 |

### 无障碍模式怎么用

打开微信某个聊天页 → 屏幕左侧出现一个可拖动的悬浮球 → 点一下 → 球变成
`...` → 生成好后弹出三条候选 → 点一条，文字填进输入框 → **你自己按发送**。

`填完顺手点发送` 开关默认关着。关着时程序只填字不点发送，留一道人工闸门，
行为上也最不像机器。

### 无障碍模式刻意没做的

不遍历会话列表、不批量群发、不自动加好友、不自动通过好友申请。
服务只在你自己打开某个聊天窗口时被动工作。那些批量能力是群控工具的范畴，
封号最快，性质也完全不同。

## 工作方式

收到私信 → 抓通知内容 → 查白名单 → 过敏感词 → 查免打扰时段和每小时限额
→ 调 AI 出 3 条候选 → 候选再过一遍出口规则 → 推到通知栏 → 你点一下发出去。

默认是**半自动**：AI 出候选，你点一下才发。想全自动可以在设置里开，
开了之后会先随机等 20–180 秒再发（秒回是风控最明显的特征）。

## 表达风格

设置第 ④ 张卡片，多选。勾几种就出几条，**每种风格各一条**，横向对照着挑；
只勾一种就是同一风格出 3 条不同写法。

| 风格 | 写出来什么样 |
| --- | --- |
| 高情商 | 先接住对方的情绪再回应，舒服但不给承诺 |
| 理性 | 就事论事，不带情绪词，不寒暄不反问 |
| 尖酸 | 带刺、反讽、绵里藏针，点到为止 |
| 高冷 | 三到八个字，让话题降温 |
| 俏皮 | 轻松玩笑、接梗 |
| 自定义 | 自己写一段风格描述，比如「东北话，自来熟」 |

候选上会标着是哪种风格：通知模式下按钮直接是风格名，无障碍模式下每条候选上方有个小标签。

想加风格改 `Tone.kt` 加一个枚举项就行，选择器和 prompt 拼装都是遍历 `entries`
自动出来的，别的地方不用动。

### 尖酸风格不参与全自动

就算总开关那边开了「全自动直接发」，尖酸的候选也只会推给你，要发得自己点。
让机器自己决定什么时候呛人，出事概率太高。

另外任何风格下都拦辱骂和人身攻击（脏话、智障废物这类，以及提对方长相收入工作家人）。
尖酸要的是反讽，不是骂街 —— 骂街既没杀伤力，也容易被举报。

## 写死的拦截规则

以下话题不生成回复，只推一条提醒让你自己看，设置里没有关闭开关：

- 钱：转账、红包、打赏、借钱、投资、理财、平台、充值、提现
- 见面：约会、开房、酒店、地址、同城线下
- 隐私：手机号、微信号、身份证、验证码、真实姓名、学校单位
- 感情承诺：喜欢你、在一起、结婚、养你、包养
- 索要图片视频

AI 生成的内容也会过同一套规则，命中的候选直接丢掉。

理由：这几类话让 AI 替你说，说错了是你担责；涉钱加感情引导的对话组合，
性质上也比较敏感，人工把关更稳妥。

## 已知限制

- **群聊不处理。** 微信群通知正文是「昵称: 内容」，一律跳过。
- **合并通知抓不到。** 多人同时发消息时微信会合并成「3 位联系人发来 5 条消息」，
  这种没有具体内容，只能跳过。
- **只能处理文字。** 图片、语音、视频、红包、转账在通知里是 `[图片]` 这种占位符。
- **拿不到聊天历史。** 上下文只能从装了这个 App 之后一条条攒，
  每人保留最近 16 条。
- **通知被清掉就发不出去了。** 快捷回复通道挂在原通知上，
  你手滑清了通知栏，那条的候选就作废了，得手动回。
- **抖音私信不一定支持。** 抖音的通知不一定带 RemoteInput 回复 action，
  开关留着但需要你自己实测。
- **需要 Android 8.0 以上。**
- **无障碍模式认界面靠猜。** 微信的 view id 是混淆的、每个版本都变，所以定位输入框、
  发送键、消息气泡走的是「结构 + 左右位置 + 文本」的启发式规则，不是写死 id。
  这样抗更新能力强很多，但遇到大改版仍可能失灵，表现是悬浮球不出现。
- **无障碍模式读不到滚上去的历史。** 只能读屏幕上当前可见的部分。
- **有封号风险。** 通知模式走的是系统 API，服务端看不到客户端异常；
  无障碍模式的行为特征则明显得多。两种模式的高频、规律化行为都可能触发风控。
  建议先拿小号跑几天，尤其是无障碍模式。

## 换 AI 服务

设置里改两处：

| 服务 | 接口地址 | 模型名 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1/chat/completions` | `moonshot-v1-8k` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-4-flash` |

## 数据

所有配置和对话上下文存在本机 SharedPreferences 里，没有服务端。
消息内容只会发给你自己填的那个 AI 接口。
