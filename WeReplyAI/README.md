# 私信助理（WeReplyAI）

一个悬浮球。你把对话复制/粘贴给它，它拆成一轮一轮交给 AI，
生成几条不同风格的回复，点一条就复制好。

**不读微信屏幕、不读通知、不用无障碍**，内容全是你自己递进去的，
微信那边看不到任何异常，没有封号风险。只要两个权限：悬浮窗 + 通知。

读屏和通知监听那两条路还留着，但都退到可选位置了 —— 它们靠猜微信的界面结构，
微信一改版就失灵，不该是主路。

## 出 APK

容器里没有 Android SDK，编不出包。把整个目录推到 GitHub，
Actions 会自动跑 `.github/workflows/build.yml`，跑完在 Actions 页面下载
`wereply-debug-apk`。

```bash
cd WeReplyAI
git init && git add . && git commit -m "init"
git remote add origin git@github.com:你的账号/WeReplyAI.git
git push -u origin main
```

## 装好之后（剪贴板模式，默认）

只要两个权限：**允许发送通知** + **允许显示悬浮窗**。
打开 App，最上面「准备工作」两项都打勾，点「启动悬浮球」就行。

顺手把「你自己的微信昵称」填上 —— 整段对话贴进来时靠它分清哪几条是你说的。

### 轻点球 —— 一条消息，直接出候选

1. 微信里长按对方那条消息，选「复制」
2. 轻点球，等一两秒
3. 挑一条，点它就复制好了
4. 回微信输入框长按，粘贴，发送

### 长按球 —— 攒对话面板

想让 AI 看到好几条再回的时候用这个。面板上：

| 按钮 | 干嘛的 |
| --- | --- |
| 读剪贴板 | 反复点。复制一条，收一条，攒着 |
| 用粘贴的 | 长按上面的框粘贴整段对话，点这个收进来 |
| 读屏幕 | 开了读屏增强才出现，直接读当前聊天页 |
| 角色对调 | 谁是谁判反了，一键翻过来 |
| 清空 | 换人聊天时点 |
| 生成回复 | 收够了点这个 |

列表里每条**点一下**切换「对方 / 我」，**长按**删掉。
选中的候选会自动记成你说的那条，接着聊不用重新攒。

## 怎么把多条对话弄进剪贴板

先说清楚一件事：**安卓微信的「多选」底部只有删除、转发、收藏，没有「复制」。**
一次性把多条消息复制走这条路在安卓上不存在，别在那儿找了。实际能走的是这几条：

| 办法 | 步数 | 说明 |
| --- | --- | --- |
| **一条条复制 + 反复点「读剪贴板」** | 每条 3 下 | 安卓上最实际的路。攒几条就点几次 |
| **多选 → 收藏 → 我·收藏 → 打开 → 右上角 → 转为笔记 → 全选复制** | 约 6 下 | 一次拿到整段，粘进面板的框里 |
| **微信电脑版多选复制** | 1 下 | 电脑版是真的能多选复制，格式是「昵称 + 时间戳」，解析器认得。跨设备粘贴用微信输入法或者发给文件传输助手 |

不管哪条路进来的文字，都会先过一遍解析器。

### 解析器认得四种形状

按可靠性从高到低依次尝试，第一个认出来的算数：

| 形状 | 长什么样 | 谁会产生 |
| --- | --- | --- |
| 时间戳抬头 | `小王 2026-09-08 10:23:45` 换行 `在吗` | 微信电脑版多选复制、邮件备份 |
| 行内前缀 | `小王：在吗` | 收藏转笔记、各种导出工具 |
| 昵称独占一行 | `小王` 换行 `在吗` | 部分笔记导出 |
| 都不认识 | —— | 整段当成对方连发的一段，不丢内容 |

解析结果会显示在面板顶上：用了哪种格式、拆出几条、对方是谁、你说了几条。
对不对你一眼能看出来，不对当场改。

### 谁是「我」谁是「对方」怎么定

1. 填了自己的微信昵称，就按昵称对 —— 最准，这种情况下轻点球会一路生成到底
2. 没填，就把**整段最后说话的那个人**当成对方（你本来就是在回他）
3. 判反了点「角色对调」，或者单条点一下切换

猜错不会罢工。宁可判错让你一键翻过来，也不弹一句「解析失败」把你晾在那儿。

### 顺带清掉的噪声

复制聊天记录经常带进来一堆没用的行，这些会自动丢掉：
「以下为新消息」、「查看更多消息」、单独一行的时间（`昨天 21:30`、`下午 3:15`）、
「xxx撤回了一条消息」、分隔线。

不丢会出事 —— 比如 `昨天 21:30` 会被「昵称：内容」认成昵称是「昨天 21」、内容是「30」。

### 太长了会怎样

超过 8000 字只留最后一段，对话是从后往前有用的。
发给接口之前还会再整理一遍：按 3000 字预算从后往前裁、合并连续同角色的消息
（一个人连发三条是常态，多数接口不喜欢连续同角色）、结尾补一句免得模型去续写你自己那条。

## 读屏增强（可选，能不能用都不影响主流程）

### 开关在哪

在悬浮球那张卡片里打开开关，然后**还要去系统设置里把无障碍服务真的打开**。
这两步是分开的 —— App 里的开关只是意愿，系统开关才算数。
只开了前者的话，卡片上会弹一个红色提示，附带跳转按钮。

开了之后，攒对话面板上会多一个「读屏幕」按钮。**它是可选的加速器，不是必需品** ——
读不出来就别管它，复制消息那条路完全不依赖它。

它跟高级模式里的无障碍模式**不是一回事**：这里的无障碍服务只当按需读取器用，
只有你点「读屏幕」那一下才会读一次，没有自动监听、没有自动发送、不需要白名单。

**读的是整屏对话，不是只读最后一条。** 屏幕上可见的每条消息都会被读出来，
靠气泡在屏幕左边还是右边判断是谁说的，再按纵向位置排成时间顺序，
整段作为上下文发给 AI。RecyclerView 缓存住的、刚滚出屏幕一点的那几行也会顺带捞到。
面板上会显示「读屏 · N 条对话 · 对方昵称」，读得对不对你一眼能看出来。

### 节点识别为什么不看类名

微信的类名是混淆的，消息气泡用的还是自家自定义控件（为了渲染表情），
既不叫 `TextView` 也不叫 `RecyclerView`。按类名匹配必然筛空。

所以判据全部换成跟命名无关的：

- **消息** = 叶子节点 + 有文字 + 落在标题栏下沿和输入框上沿之间
- **输入框** = `isEditable`（切到「按住 说话」语音模式时没有可编辑节点，会返回 null，调用方兜住）
- **谁说的** = 先按中心点定下明确靠左靠右的，用它们校准出左右两条泳道的边界，
  再回头处理那些几乎占满屏宽、中心点说明不了问题的长消息
- **语音消息** 在节点树里就是个时长（`14"`），换成 `[语音]` 占位，保住对话轮次

### 之前读不到微信屏幕，改了什么

两处，都是「读到 0 条」的典型成因：

- **`accessibility_service_config.xml` 少了 `flagIncludeNotImportantViews`。**
  微信的消息气泡大量标了 `importantForAccessibility="no"`，不加这个 flag
  它们**压根不会出现在节点树里**。这是头号嫌疑。
- **节点筛选要求 `childCount == 0`（只取叶子）。**
  微信的气泡是自绘控件，里面常常还挂着表情之类的子节点，按叶子筛会把整条消息筛掉。
  改成「自己有文字、且子树里没有别的文字节点」，容器和叶子都能兜住；
  文字为空时还会退回去取 `contentDescription`（表情消息常挂在那儿）。

另外上下边界也放开了：先按「标题栏到输入框之间」读一遍，一条都没读到就把上下界
撤掉重读一次，免得微信改版挪了输入框位置就整个读空。

改完还是读不到就别折腾了 —— 剪贴板那条路不依赖节点树，微信怎么改版都影响不到它。

### 自检模式

读屏出问题时，在悬浮球卡片里打开「自检模式」，点「读屏幕」不会调 AI，
只把这一屏读成什么样列出来：包名、有没有找到输入框、读到几条、每条判成谁说的。
哪一步不对一眼能看见。用完记得关掉。

### 读屏失败了

不会静默降级，面板上会直接告诉你卡在哪一步：

| 提示 | 意思 |
| --- | --- |
| 无障碍服务没生效 | 系统设置里的开关没开，或者要关掉再打开一次 |
| 取不到当前窗口 | 权限刚开还没生效，重开一次无障碍 |
| 在「xxx」里没找到聊天记录 | 你不在聊天页，或者那个 App 的界面结构不认识 |
| 都判成你自己发的了 | 往上滑一点让对方的消息露出来 |

## 为什么面板会盖住半个屏幕

Android 10 之后，只有**持有焦点的窗口**才能读剪贴板。后台服务读不到。
所以点球之后必须先弹出一个能拿焦点的面板，焦点落定了才读得到你复制的内容。
这不是设计取舍，是系统限制绕不过去。

## 球自己消失了

前台服务带常驻通知，一般能扛住。扛不住的话就是厂商的后台限制太狠，
点悬浮球那张卡片里的「电池优化」和「自启动」两个按钮去关掉，
路径按你的手机品牌自动匹配。

## 高级模式（可选，默认折叠）

在「高级模式」卡片里展开，能切到另外两种自动模式：

| | 剪贴板 | 通知模式 | 无障碍模式 |
|---|---|---|---|
| 要开的权限 | 2 个 | 4 个 + 微信设置 | 5 个 |
| 触发方式 | 手动复制 + 点球 | 自动 | 自动 |
| 上下文 | 你复制多少算多少 | 只有通知那一条 | 屏幕上可见的全部 |
| 支持哪些 App | 所有 | 微信为主 | 微信、抖音 |
| 封号风险 | 无 | 低 | 明显更高 |

通知模式靠通知栏的快捷回复通道，无障碍模式读聊天界面并填进输入框。
两个都能自动触发，代价是权限多、有风险。**剪贴板模式够用就别碰这里。**

白名单、节流、免打扰时段、全自动直接发这些设置只对自动模式有意义，
所以也一并收进高级模式里了。

## 表达风格

设置第 ④ 张卡片，多选。勾几种就出几条，**每种风格各一条**，横向对照着挑；
只勾一种就是同一风格出 3 条不同写法。

| 风格 | 写出来什么样 |
| --- | --- |
| 高情商 | 先接住对方的情绪再回应，舒服但不给承诺 |
| 理性 | 就事论事，不带情绪词，不寒暄不反问 |
| 尖酸 | 带刺、反讽、绵里藏针，点到为止 |
| 高冷 | 三到八个字，让话题降温 |
| 俏皮 | 轻松玩笑、接梗 |
| 自定义 | 自己写一段风格描述，比如「东北话，自来熟」 |

候选上会标着是哪种风格：通知模式下按钮直接是风格名，无障碍模式下每条候选上方有个小标签。

想加风格改 `Tone.kt` 加一个枚举项就行，选择器和 prompt 拼装都是遍历 `entries`
自动出来的，别的地方不用动。

### 尖酸风格不参与全自动

就算总开关那边开了「全自动直接发」，尖酸的候选也只会推给你，要发得自己点。
让机器自己决定什么时候呛人，出事概率太高。

另外任何风格下都拦辱骂和人身攻击（脏话、智障废物这类，以及提对方长相收入工作家人）。
尖酸要的是反讽，不是骂街 —— 骂街既没杀伤力，也容易被举报。

## 关于内容限制

关键词拦截全部去掉了。候选只做两件事：非空、不超过 120 字。
内容上不设限，该冷就冷、该呛就呛，由你自己从候选里挑。

去掉的三张表和去掉的理由：

- **对方消息拦截表** —— 对方消息里出现什么词，跟你的回复是否合适没有关系。
  按对方的用词决定要不要生成本来就是错的设计，实际效果是粉丝随口提一句就整个罢工。
- **输出拦截表** —— 静默丢弃候选更糟，你根本不知道被丢了什么。
- **辱骂表** —— 误伤太重，日常口语里的「丑」「贱」「有病吧」全在里面，尖酸风格基本被废掉。

只有一条约束留在 `AiClient` 的 system prompt 里：不主动引导对方打赏、转账、
充值、投资。对方自己提到钱会正常回应，只是不顺势索要。
这条不拦候选、不静默丢东西，你不会遇到「这条怎么没了」的情况。

另外「尖酸风格不参与全自动」保留着，但它只在高级模式的全自动直接发下生效 ——
那个模式本来就没有你的审阅环节。剪贴板模式下完全不起作用。

## 已知限制

- **群聊不处理。** 微信群通知正文是「昵称: 内容」，一律跳过。
- **合并通知抓不到。** 多人同时发消息时微信会合并成「3 位联系人发来 5 条消息」，
  这种没有具体内容，只能跳过。
- **只能处理文字。** 图片、语音、视频、红包、转账在通知里是 `[图片]` 这种占位符。
- **拿不到聊天历史。** 上下文靠你自己复制/粘贴进来，最多保留 40 条。
- **通知被清掉就发不出去了。** 快捷回复通道挂在原通知上，
  你手滑清了通知栏，那条的候选就作废了，得手动回。
- **抖音私信不一定支持。** 抖音的通知不一定带 RemoteInput 回复 action，
  开关留着但需要你自己实测。
- **需要 Android 8.0 以上。**
- **无障碍模式认界面靠猜。** 微信的 view id 是混淆的、每个版本都变，所以定位输入框、
  发送键、消息气泡走的是「结构 + 左右位置 + 文本」的启发式规则，不是写死 id。
  这样抗更新能力强很多，但遇到大改版仍可能失灵，表现是悬浮球不出现。
- **读屏读不到滚上去的历史。** 只能读屏幕上当前可见的部分（外加 RecyclerView
  缓存的一两屏）。想给 AI 更多上下文，点「读屏幕」之前先往上滑一下。
- **安卓微信没有一键多选复制。** 这是微信的限制，不是本程序的。
  绕法见上面那张表。
- **部分厂商会弹「私信助理读取了剪贴板」的提示。** 正常现象 ——
  Android 10 之后只有持焦点的窗口能读剪贴板，面板抢焦点那一下就会触发提示。
- **有封号风险。** 通知模式走的是系统 API，服务端看不到客户端异常；
  无障碍模式的行为特征则明显得多。两种模式的高频、规律化行为都可能触发风控。
  建议先拿小号跑几天，尤其是无障碍模式。

## 数据

所有配置和对话上下文存在本机 SharedPreferences 里，没有服务端。
消息内容只会发给你自己填的那个 AI 接口。
